# Pinned, compatible-release versions of the runtime dependencies.
# The `~=` operator means "this major.minor, any patch >= this one".
#
# Why pinning matters: the original `launch.bat` ran `pip install --upgrade`
# on every launch, which means matplotlib today ≠ matplotlib tomorrow and
# your charts can silently shift appearance between runs.
#
# To upgrade deliberately:  pip install -U -r requirements.txt
